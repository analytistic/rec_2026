# Data Overview

## Raw Data (sample_data.parquet)

1000 samples, 7 columns: `user_id`(str), `item_id`(int), `timestamp`(int), `label`, `user_feature`, `item_feature`, `seq_feature`

**Label**: `action_type` 1=点击(897), 2=转化(103)
